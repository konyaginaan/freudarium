## Формула Липпса

Возврат от переоценки свойства сознания — непременное условие для верного понимания хода психического. Бессознательное должно быть принято как ОБЩАЯ ОСНОВА душевной жизни — больший круг, включающий в себя меньший круг сознательного. Всё сознательное имеет бессознательную предступень, тогда как бессознательное может остаться на этой ступени и всё же притязать на полную ценность психического достижения.

## Знаменитая формула

**«Бессознательное — подлинно реальное психическое, столь же неизвестное нам по своей внутренней природе, как реальность внешнего мира, и данное нам через данные сознания столь же неполно, как внешний мир — через показания наших органов чувств.»**

## Значение

Одна из самых часто цитируемых фраз всей книги: приравнивает эпистемологический статус бессознательного к статусу внешнего физического мира — оба непознаваемы напрямую, оба доступны лишь через неполные, опосредованные данные (органы чувств для мира; сознание для психики). Это ставит психоанализ в один ряд с естественными науками по строгости метода.
