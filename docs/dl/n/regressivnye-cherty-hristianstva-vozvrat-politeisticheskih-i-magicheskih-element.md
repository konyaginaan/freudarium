Христианство отчасти означает культурный регресс относительно достигнутой иудаизмом высоты одухотворения: оно вновь впускает магические и мистические элементы, восстанавливает культ великой богини-матери, находит место многочисленным политеистическим фигурам в подчинённом виде — «как будто Египет отомстил наследникам Эхнатона».
