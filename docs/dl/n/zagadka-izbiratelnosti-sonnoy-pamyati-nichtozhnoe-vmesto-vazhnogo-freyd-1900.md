## Наблюдение Гильдебрандта

Самая непонятная из трёх особенностей сонной памяти: сон явно предпочитает не важное, а безразличное. Потрясающее, эмоционально нагруженное событие дня стирается из содержания сна, а бородавка на лбу случайно встреченного и тут же забытого прохожего становится полноценным сюжетом ночного видения.

## Значение

Литература XIX века фиксирует этот факт как курьёз, не находя ему систематического объяснения — простая «важность» впечатления явно не определяет его шансы попасть в сон. Загадка избирательности остаётся открытой в главе I; её решение (смещение психической ценности с важного элемента на незначительный по соседству через ассоциативную связь) станет одним из центральных механизмов работы сновидения, которые Фрейд опишет позже.
