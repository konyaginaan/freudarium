Источник:: [[Новые вводные лекции — конспект, Фрейд, 1933]]

Учреждение Сверх-Я теснейшим образом связано с судьбой Эдипова комплекса: отказавшись от интенсивных объектных привязанностей к родителям (которые должны быть преодолены), ребёнок компенсирует эту утрату резким усилением уже имевшихся идентификаций с родительскими фигурами. Отсюда формула — Сверх-Я есть наследник Эдипова комплекса.
