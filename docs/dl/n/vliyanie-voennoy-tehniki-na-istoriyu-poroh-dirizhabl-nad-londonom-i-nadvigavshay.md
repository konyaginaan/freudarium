Источник:: [[Новые вводные лекции — конспект, Фрейд, 1933]]

Фрейд иллюстрирует влияние прогрессирующего покорения природы на социальные отношения: порох положил конец рыцарству; появление аэроплана (перелёт Блерио через Ла-Манш, ночной учебный полёт немецкого цеппелина над Лондоном) разрушило вековую островную безопасность Англии и, по личным сведениям Фрейда, ускорило решение о войне против Германии уже в первый год Мировой войны. Спекулятивно добавляет: нынешний экономический кризис отчасти может быть «ценой» последней великой победы над стихией — покорения воздуха.
