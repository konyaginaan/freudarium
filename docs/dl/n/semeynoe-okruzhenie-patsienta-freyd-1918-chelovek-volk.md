Источник:: [[Человек-Волк — конспект, Фрейд, 1918]]

Молодые женатые родители ведут поначалу счастливый брак, на который вскоре ложатся первые тени болезней — недомогания матери по женской части и первые приступы дурного настроения отца, влёкшие его отлучки из дома. Болезнь отца пациент понимает лишь много позже, а болезненность матери становится ему известна уже в ранние детские годы, отчего она сравнительно мало занималась детьми. Однажды, ещё до четырёх лет, он, ведомый матерью за руку, слышит её жалобы врачу и запоминает её слова, чтобы позже использовать их для себя самого. У него есть на два года старшая сестра — живая, одарённая и не по годам испорченная, которой суждено сыграть большую роль в его жизни. За ним ухаживает няня — необразованная старая женщина из народа безграничной нежности к нему; он для неё — заместитель собственного рано умершего сына.
