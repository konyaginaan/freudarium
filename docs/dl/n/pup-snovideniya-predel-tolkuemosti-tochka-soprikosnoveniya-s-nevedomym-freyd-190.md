## Признание Фрейда

Завершив разбор сна об Ирме, Фрейд честно признаёт: анализ не исчерпывает сон до дна. Есть нити ассоциаций, которые он сознательно не тянет дальше — отчасти из соображений личной сдержанности (не всё из своей интимной жизни он готов раскрыть читателю), отчасти потому что сам чувствует: дальнейшее толкование увело бы слишком далеко.

## Формулировка

Отсюда общее методическое наблюдение, которое Фрейд делает по ходу дела, но которое остаётся в силе для всей дальнейшей книги: у каждого сновидения есть по меньшей мере одно место, не поддающееся до конца истолкованию, — точка, в которой сон соприкасается с неведомым, словно связан с ним пуповиной.

## Значение

Редкий момент методологической скромности внутри книги, которая в остальном демонстрирует почти безграничную толковательную уверенность: Фрейд заранее отказывается от претензии на исчерпывающее, полное без остатка толкование любого сна — граница толкуемости признаётся структурной чертой самого сновидения, а не недостатком метода или толкователя.
