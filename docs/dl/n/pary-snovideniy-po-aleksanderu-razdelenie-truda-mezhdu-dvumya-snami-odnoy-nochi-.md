Источник:: [[Новые вводные лекции — конспект, Фрейд, 1933]]

Ф. Александер (1925) показал на «парах сновидений» одной ночи, как задача исполнения желания может делиться между двумя сюжетами: один сон называет лицо без действия, другой — действие без лица; либо один сон изображает наказание, а другой — грешное исполнение желания, за которое это наказание полагается, — так, будто одному сну не под силу удержать оба полюса компромисса разом.
