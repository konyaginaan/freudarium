Источник:: [[Очерк психоанализа — конспект, Фрейд, 1940]]

Феномены раннего детства проходят закономерное развитие с регулярным нарастанием, достигающее подъёма к концу пятого года жизни; за ним следует латентный период — застой развития, частичное разучивание достигнутого, — а по окончании этой латентности с пубертатом сексуальная жизнь продолжается, словно расцветает заново. Этот двухфазный старт сексуальной жизни неизвестен вне человека и, по-видимому, крайне важен для очеловечивания.
