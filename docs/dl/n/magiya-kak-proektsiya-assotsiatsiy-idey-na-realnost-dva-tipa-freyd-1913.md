## Два типа магии (по Фрэзеру)

- **Имитативная (гомеопатическая) магия** — действие производится над подобием желаемого результата или объекта: восковая фигурка врага, которую колют, чтобы поразить его самого; ритуальное совокупление в поле для стимуляции плодородия риса; сжигание изображения демона египетскими жрецами для обеспечения победы солнечного бога.
- **Заразительная (контагиозная) магия** — действие производится над частью объекта или предметом, ранее находившимся с ним в контакте (волосы, ногти, одежда, оружие, причинившее рану): меланезиец бережёт лук, которым был ранен, в прохладном месте, чтобы рана не воспалилась; английские крестьяне смазывают маслом орудие пореза вместо самой раны.

## Общий принцип

Тайлор формулирует принцип, лежащий в основе обоих типов: «принятие идеальной связи за реальную» — то есть смешение порядка идей (сходство, смежность) с порядком вещей в природе. Оба типа магии — прямая проекция двух базовых принципов ассоциации идей (сходство и смежность/контакт) на реальный физический мир: если между двумя идеями есть связь по сходству или по смежности, примитивное мышление считает такую же связь существующей и между реальными вещами.

## Значение

Ассоциативная теория магии (Тайлор/Фрэзер) объясняет только путь, по которому движется магическое мышление, но не объясняет его глубинную природу — то есть само смешение психологических законов с законами природы. Это смешение Фрейд объясняет дальше через понятие «всемогущества мысли».
