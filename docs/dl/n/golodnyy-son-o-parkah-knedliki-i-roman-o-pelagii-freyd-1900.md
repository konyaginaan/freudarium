## Сон

Вернувшись из поездки усталым и голодным, Фрейд видит сон: идёт на кухню за мучным блюдом; там три женщины, одна из них хозяйка, лепит что-то вроде кнедликов и просит подождать; он уходит обиженным; примеряет два пальто (одно с меховой отделкой, другое с турецким узором); незнакомец с острой бородкой объявляет второе пальто своим, но затем они дружелюбны.

## Первая ассоциация

При анализе неожиданно вспоминается первый прочитанный роман (лет в тринадцать), начатый прямо с конца первого тома: имени автора и романа Фрейд так и не узнал, но конец помнит живо — герой сходит с ума, без конца выкрикивая три женских имени, означавших для него величайшее счастье и несчастье; Пелагия — одно из этих имён.

## Значение

Один из самых знаменитых снов книги («сон о голоде» / «сон о Парках») — открывает собой пример того, как физиологическая потребность (голод после дороги) сплетается с чисто литературной, тринадцатилетней давности ассоциацией, задавая тон всему дальнейшему разбору.
