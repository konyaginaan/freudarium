## Два типа

Гомосексуальный выбор объекта изначально ближе к нарциссизму, чем гетеросексуальный. Продвижение выбора объекта после нарциссической стадии может идти по одному из двух типов: **нарциссический тип** — объектом становится личность, во многом подобная собственному Я; **зависимый (анаклитический, «примыкающий») тип** — объектом становятся лица, ставшие ценными благодаря удовлетворению иных, не либидинозных потребностей жизни (например, кормящая мать, защищающий отец). Сильная фиксация либидо на нарциссическом типе выбора объекта предрасполагает к явной гомосексуальности.

## Значение

Прямое продолжение более ранней темы (лекция 21) о матери как первом объекте любви, возникающем на исходе оральной привязанности, — здесь она получает своё теоретическое имя («анаклитический тип»), а её альтернатива (выбор по образу себя самого) впервые явно названа и связана с судьбой гомосексуальности. Позже это различение станет одним из ключевых понятий метапсихологии Фрейда (развёрнуто, в частности, в статье «О нарциссизме», 1914).
