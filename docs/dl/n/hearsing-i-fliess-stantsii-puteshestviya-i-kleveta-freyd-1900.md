## Станция Hearsing

В долгом путаном сне Фрейда о морском путешествии следующая станция называется Hearsing, а за ней — Fliess (имя берлинского друга). Hearsing составлено из венских пригородных станций на «-ing» (Hietzing, Liesing, Mödling = «meae deliciae», то есть «моя Фрейд[е]») и английского hearsay («слухи») — намёк на клевету, связанный с безразличным дневным поводом (стишок о клеветническом гноме).

## Vlissingen/Flushing

Через окончание «-ing» с именем Fliess получается «Vlissingen» — реальная станция морского пути брата Фрейда из Англии; английское название того же города — Flushing («покраснение»), напоминающее о пациентах с боязнью покраснения и о недавней раздражавшей Фрейда публикации Бехтерева на эту тему.

## Значение

Один из самых сложных примеров многоязычного сгущения в книге — немецкие топонимы, латинская этимология, английское слово с двойным значением и профессиональная досада сплетены в единственном искусственном слове-станции.
