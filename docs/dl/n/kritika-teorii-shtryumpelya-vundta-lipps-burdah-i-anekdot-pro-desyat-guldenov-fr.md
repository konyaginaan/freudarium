## Возражение Липпса

Любой соматический раздражитель может вызвать бесчисленные попытки толкования — теория Штрюмпеля-Вундта неспособна указать мотив, регулирующий отбор ИМЕННО этого представления для толкования раздражителя, то есть объяснить «странный отбор», которому раздражители подвергаются (Липпс).

## Возражение Бурдаха

Другая линия критики бьёт по самой предпосылке — будто душа во сне не способна распознать истинную природу раздражителя. Бурдах показывает: душа и во сне способна верно толковать важные впечатления и реагировать сообразно (кормилица слышит ребёнка, собственное имя будит вернее безразличного звука) — значит, дело не в неспособности, а в недостатке интереса. Те же доводы неизменными повторяет Липпс в 1883 году. Душа предстаёт подобной спящему из анекдота: на «Ты спишь?» отвечает «Нет», но на «Тогда одолжи десять гульденов» укрывается отговоркой «Я сплю».

## Значение

Двойной удар по теории: она не может объяснить ни специфику отбора (Липпс), ни саму предпосылку неспособности к верному толкованию (Бурдах) — расчищает почву для собственного объяснения Фрейда через понятие сонного желания.
