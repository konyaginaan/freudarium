## Пять новых психических инструментов

Введение принципа реальности потребовало не одной, а целой серии новых психических функций, каждая — прямой ответ на конкретную задачу приспособления к внешнему миру:

1. **Внимание** — периодически обследует внешний мир заранее, чтобы его данные были уже знакомы, если возникнет неотложная внутренняя потребность; действует навстречу впечатлениям, а не ждёт их пассивно.
2. **Память (система записи)** — откладывает результаты этой периодической деятельности сознания.
3. **Суждение** — вместо вытеснения (исключавшего болезненные идеи из катексиса) развивается беспристрастная инстанция, решающая, истинна идея или ложна, — то есть согласуется ли она с реальностью; решение определяется сравнением со следами памяти о реальности.
4. **Действие** — двигательная разрядка, прежде служившая лишь освобождению психики от накоплений раздражения (мимика, аффективные проявления), теперь используется для целесообразного изменения реальности.
5. **Мышление** — развивается из представления специально для того, чтобы сдерживать двигательную разрядку; это, по существу, экспериментальный способ действования, сопровождаемый смещением малых количеств катексиса при меньших затратах — своего рода «проба действия» с низкой ценой ошибки. Для этого требуется превращение свободного катексиса в «связанный» — достигаемое повышением уровня всего катектического процесса.

## Значение

Это одна из самых компактных схем во всём корпусе Фрейда, показывающая, что «взросление психики» — не абстрактная метафора, а буквально сборка конкретного набора инструментов, каждый из которых решает узкую задачу (заранее знать мир / хранить знание о нём / отличать мысль от факта / действовать / пробовать действие без риска). Формула «мышление — экспериментальное действие с малыми затратами энергии» — прямой предшественник позднейших описаний мышления как способа откладывать разрядку влечения (Бион, «переносимость фрустрации» как условие способности думать).
